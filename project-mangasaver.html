MangaSaver

A local image-library toolkit that grew from organising chapter downloads into a responsive, right-to-left desktop reader.

Python / PySide6 / Qt Widgets / Local files

  1. Organise chapter images
  2. Index the local library
  3. Load visible spreads
  4. Save progress and covers

What It Does

MangaSaver brings together image-download utilities, chapter organisation and a desktop reading interface. The reader supports paired pages, zoom, chapter overviews, resume points, custom covers and switching between matching black-and-white and colour editions.

How It Works

Download tools use supplied manifests or matching URLs from supplied page sources. The library is filesystem-backed, with cover choices, reading progress and page-pairing settings stored as local metadata. The newer CPU reader uses a custom-painted Qt Widgets viewport: only visible or nearby chapter covers request thumbnails.

A disk cache, adjacent-spread prefetching and double buffering reduce repeated decoding and flashes between pages. Cover alignment provides translation and scale controls, including finer adjustments with modifier keys.

What Needed Solving

Cover alignment could freeze even after a diagnostic reported success. The test had warmed up image bindings that were still cold during normal use. A closer reproduction captured two thumbnail workers deadlocking while initializing a PySide image constructor. Initializing that constructor on the GUI thread before launching workers resolved the reproduced fault.

Lessons From Development

A passing test is only useful if its starting conditions match the failure. Cold caches, the real window dimensions and the actual navigation path mattered here. External stack capture revealed a native deadlock that ordinary Python logging could not explain. Restoring the chapter and scroll position after alignment was also part of making the workflow feel complete.

Current Scope

A local downloader and reader, with browser and older desktop variants alongside the CPU renderer. Library content remains on the user's machine; this portfolio page does not distribute the image collection.
