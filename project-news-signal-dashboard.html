Data systems / Relationship analysis

NewsSignalDashboard

Collecting investment-relevant articles and examining how their measurable features relate to subsequent market movement.

Node.js / PostgreSQL / Docker / Cloudflare

  1. Collect and classify articles
  2. Extract ticker features
  3. Track market observations
  4. Publish relationship snapshots

What It Does

NewsSignalDashboard brings an article corpus, company references and market observations into one research interface. Its current collection workflow classifies investment relevance and identifies directly named public-company tickers. The relationship explorer compares article features with later signed price movement.

How It Works

A self-hosted backend stores articles and structured records, serves PostgreSQL-backed APIs and sends dashboard updates through authenticated WebSockets. Incremental analysis extracts direction-neutral features such as document structure, publication timing, words and ticker mentions. Cloudflare provides the edge connection to the private backend.

Large relationship queries are precomputed into daily snapshots with a fixed time cutoff. Each generation is validated before activation, so a failed build leaves the previous snapshot available. Historical prediction records remain, but new collection jobs do not predict prices or score sentiment.

What Needed Solving

The combined-horizon view originally used the starting cohort's size to calculate its confidence score. That could make a result supported by only one later observation look highly reliable. The correction calculates and filters the score from observations actually available at each horizon, before ranking or limiting results. Existing archives can be corrected when read.

Lessons From Development

An analytical dashboard can be technically functional while communicating the wrong level of evidence. Sample coverage, timing boundaries and filter order must match the claim on screen. Precomputation improved responsiveness, but preserved provenance and validation were needed to keep those snapshots trustworthy.

Current Scope

An exploratory relationship-analysis system. Its displayed confidence is a sample-volume heuristic, not statistical significance, causal evidence or proof of predictive performance.
